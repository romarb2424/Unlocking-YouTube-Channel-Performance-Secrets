# Unlocking YouTube Channel Performance Secrets

A Python and Pandas project exploring YouTube performance metrics.

## Overview

The supplied script includes 25 problem statements covering dataset structure, views, watch time, estimated revenue, subscribers, thumbnail click-through rate (CTR), impressions, likes, comments, shares, average view duration, publishing-day/month patterns, correlations, and summary statistics.

## Files
- `Unlocking YouTube Channel Performance Secrets.py` — analysis script.
- `youtube_channel_real_performance_analytics.csv` — dataset expected by the script; keep it beside the script.
- `requirements.txt` — dependencies.
- `.gitignore` — common files to exclude from Git.
- `LICENSE` — MIT license template.
- `CONTRIBUTING.md` — contribution guidelines.
- `GITHUB_UPLOAD_CHECKLIST.md` — pre-publishing checklist.

## Setup and run
1. Install Python 3.10 or newer.
2. Place the CSV in the same folder as the script.
3. Install dependencies: `python -m pip install -r requirements.txt`
4. Change the script's CSV path to a relative path: `df = pd.read_csv("youtube_channel_real_performance_analytics.csv")`
5. Run: `python "Unlocking YouTube Channel Performance Secrets.py"`

## Notes
- Correlation does not establish causation.
- Results describe this dataset and should not automatically be generalized to all YouTube channels.
- Review unusual values, including negative subscriber values, before drawing conclusions.
- Confirm you have permission to publish the dataset before uploading it publicly.
